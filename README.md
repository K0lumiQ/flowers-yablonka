# Цветы у яблоньки

Сайт цветочного магазина «Цветы у яблоньки». Чистые HTML/CSS/JS, без сборщика.

- Макет: https://www.figma.com/design/DsNMmm4NnD4772K81tRT19/ (файл «Цветы у яблоньки — Copy», аккаунт Figma l1nzy TV)
- Формат макета: мобильное приложение, ширина 375, высота экранов 812 и больше
- Опубликованная версия: _пока нет_

## Запуск

```
npx http-server -p 5176 -c-1 .
```

### Дизайн-токены (по картинкам, уточнить)

- Основной цвет кнопок и акцентов: `#CF225D` (малиново-розовый), заголовки текста тёмные `#1C1C28`-ish, серый вторичный текст, зелёный для цен/скидок/«бесплатно» (`~#2DB69B`).
- Шрифт: гуманистический гротеск (в Figma проверить название).
- Скругления: карточки и фото ~16px, кнопки-пилюли, поля 8px.
- Логотип: рукописный «Цветы у яблоньки» с пионами, бордовый.

### Правила экранов

- Нижняя панель на 5 вкладок: Главная, Каталог, Корзина (бейдж с числом), Избранное, Профиль.
- Шапка главной и каталога: геометка слева, логотип по центру, поиск справа.
- Карточка товара: слайдер фото, размеры S/M/L/XL (Маленький M 30 см, Средний L 50 см, Большой XL 80 см), характеристики (цвет, состав), доставка по Омску, отзывы, «Похожие товары», внизу панель «- 1 + В корзину за 3000 ₽».
- Каталог: карусель категорий (Классика, Авторские, В коробке, Полевые, В горшке...), переключатель плитка/список, плавающая кнопка «Фильтр».
- Корзина: «Добавить к заказу?» (конфеты, игрушки), «Применить промокод», кнопка «Оформить заказ на N ₽» над таб-баром.
- Оформление: шаг 1 способ получения (По Омску от 350 ₽, По Омской области от 380 ₽ +30 ₽/км, Самовывоз 0 ₽), адрес, дата и время (интервал или точно ко времени +100 ₽); шаг 2 получатель и способ оплаты (Apple Pay, картой онлайн, картой и наличными при получении, комиссия 1%); шаг 3 состав заказа и итог.

## Что сделано (2026-10-05)

Мобильное веб-приложение в колонке 430 px по центру (на десктопе серый фон и скруглённый «телефон»). 15 страниц:

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: карусель баннеров с автопрокруткой, популярные, со скидкой, статьи, скелетон-загрузка |
| `search.html` | Живой поиск с подсветкой, недавние запросы, спиннер, «Ничего не найдено» |
| `catalog.html` | Категории, плитка и список, шторка фильтров (букет дня, хит, новинки, цена, цвет, состав, размер) |
| `product.html?id=` | Галерея, размеры S/M/L с пересчётом цены, состав, отзывы, похожие, панель «В корзину» с анимацией полёта |
| `favorites.html` | Избранное, пустое состояние |
| `cart.html` | Количество, свайп и кнопка удаления, промокод (ЯБЛОНЬКА, ВЕСНА), «Добавить к заказу», итог с анимацией чисел |
| `checkout.html` | Оформление в 3 шага: доставка и время, получатель и оплата, итог и оплата (Apple Pay-окно) |
| `order-success.html` | Заказ оформлен (конфетти) или не оплачен, повтор оплаты |
| `order.html?id=` | Страница заказа со статус-полосой |
| `profile.html`, `login.html`, `account.html?s=` | Вход по телефону (код) и почте, восстановление пароля, профиль, заказы, адреса, уведомления, настройки |
| `salons.html` | Карта салонов (нарисованная) и список |
| `reviews.html`, `review-new.html` | Отзывы с рейтингом, новый отзыв со звёздами |

Все данные в `localStorage` (корзина, избранное, пользователь, заказы, отзывы). Сброс: «Профиль → О приложении → Сбросить демо-данные».

Демо-логика оплаты: Apple Pay, наличные и карта при получении проходят сразу; «Картой онлайн» при первой попытке даёт ошибку оплаты, «Попробовать ещё раз» проходит.

### Анимации

Появление страниц, смена шагов оформления, нижние шторки, скелетон-загрузка, плавное появление блоков при прокрутке (IntersectionObserver), «пружинное» сердечко, бейдж корзины, полёт товара в корзину, пересчёт цены, ripple на кнопках, свайп-удаление, рисование галочки и конфетти при успехе, переход между страницами (View Transitions). При `prefers-reduced-motion` анимации отключаются.

## Заметки

- Не использовать `position: fixed` внутри `.page`, если у `.page` есть анимация с `fill-mode: both`: transform оставляет контейнер для fixed. Сейчас анимация без `both`.
- Запуск только через статический сервер, не через `file://` (`?id=` и шрифты).
